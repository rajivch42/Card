# विपुल संग सेजल — Royal Wedding Invitation (11 December 2026)

A mobile-first, luxury digital wedding invitation website crafted for **Vipul Chaurasiya & Sejal Chaurasia** with an **Awadhi Royal** aesthetic (Patti, Pratapgarh, Uttar Pradesh).

---

## ✨ Features
- 💌 **Interactive Royal Envelope Opening:** Wax seal break interaction with radiant golden light transition and automatic music initiation (no passcodes needed).
- 🎵 **Traditional Indian Wedding Instrumental:** Plays melodic flute & sitar melody (*Jashn-e-Bahara*) with floating mute/unmute control.
- 🌸 **Floating Canvas Petals:** Lightweight Canvas 2D falling rose, marigold, and gold dust petals.
- 🪔 **Divine Blessing Card:** Sacred Radha-Krishna miniature artwork, Sanskrit Ganesha shloka, and family lineage honors.
- ❤️ **Save the Date Scratch Hearts:** Three interactive scratch cards revealing Day (11), Month (12), and Year (2026) with celebratory flower petal confetti.
- ⏳ **Live Countdown Timer:** Synchronized to 11th December 2026, 19:00 IST.
- 🏛️ **Sacred Ceremonies Carousel:** Interactive cards for Havan (9 Dec), Haldi (10 Dec), and Shubh Vivah (11 Dec) with micro-animations and direct Google Maps buttons.
- 🗺️ **Venue & Travel Guide:** Illustrated Awadhi venue artwork with transit directions (train, airport, parking) and turn-by-turn navigation.
- 📜 **Royal Closing Screen:** Deep burgundy backdrop with family host blessings (*दर्शनाभिलाषी: समस्त चौरसिया परिवार*).
- 🌐 **Bilingual (Hindi / English):** Primary language in pure Hindi (Devanagari) with an English toggle available.

---

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + Custom CSS Variables
- **Animations:** Canvas 2D, CSS keyframes, Canvas Confetti
- **Typography:** Google Fonts (Tiro Devanagari Hindi, Great Vibes, Cinzel, Cormorant Garamond)
- **Deployment:** Vercel

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
